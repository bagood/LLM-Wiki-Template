## Summary

The note recommends local Markdown for durable memory in a small personal assistant. It pairs that storage choice with progressive reading: start with a compact index, then open relevant summaries. It also requires explicit source identity and citations to keep unsupported claims out of persistent knowledge.[^local-memory-015a1edd3c08060e]

## Key claims

- Local Markdown is recommended for a personal assistant with a small collection.[^local-memory-015a1edd3c08060e] [Passage](../../raw/local-memory-015a1edd3c08060e/local-memory.md#recommendation)
- A compact index should guide which summaries are read.[^local-memory-015a1edd3c08060e] [Passage](../../raw/local-memory-015a1edd3c08060e/local-memory.md#recommendation)
